# 📦 E-Commerce Shipping & Delivery Analysis

### E-Commerce Shipping Intelligence Dashboard

An interactive Data Analytics project developed using Python and Streamlit to analyze e-commerce delivery performance, shipping trends, seller performance, and logistics operations.

## 🚀 Project Overview

The E-Commerce Shipping Intelligence Dashboard transforms raw e-commerce data into meaningful business insights through interactive visualizations, performance metrics, geographical analysis, and delivery analytics.

## ✨ Key Features

- **Executive Overview:** Delivery KPIs and business performance summaries.
- **Delivery Analytics:** Delivery trends, delays, and performance analysis.
- **Geographical Insights:** Interactive Brazil delivery map and state-level analysis.
- **Seller Performance:** Seller rankings and performance comparisons.
- **Logistics Intelligence:** Carrier and handoff performance analysis.
- **Business Insights:** Data-driven findings and recommendations.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Vidya0210/Ecommerce_Shipping_Analysis.git
```

### 2. Navigate to the project folder

```bash
cd Ecommerce_Shipping_Analysis
```

### 3. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 4. Run the Streamlit dashboard

```bash
python -m streamlit run app.py
```

The dashboard will open in your web browser.
